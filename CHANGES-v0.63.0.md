# PokemonCollege v0.63.0

## Edit Problem Sets (mid-run)
- **Run Settings** (the gear during a Mystery Dungeon or Tower run) has a new **📚 EDIT PROBLEM SETS** button.
- It shows the same set list as when you start a run, grouped by folder, with this run's current sets ticked.
- Pick different sets and press SAVE. Questions come from the new sets right away, and your floor, team, items, tickets and timer stay the same.
- The change is saved with the run, so it's still there after you close and reopen the app.
- Same checks as starting a run: you need at least one set, and those sets need questions for the run's study mode (Smart Study / Learn / Review Weak Points).
