# PokémonCollege v0.37.2 — TM learnsets
- **Real learnsets:** TMs now follow each Pokémon's learnset from the main games (any generation, any method, including moves its pre-evolutions learn), checked against all 111 moves in the app. Before, a Pokémon could only learn the 4 moves in its own move pool.
- **Mew** can learn every move.
- **Moves you already have:** every move a Pokémon already knows stays learnable.
