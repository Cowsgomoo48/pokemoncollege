# PokémonCollege v0.59.2

## New battle items (Mystery Dungeon and Battle Tower)
- **🧂 Smelling Salts** (★★ Uncommon · 20 Tickets in shops):
  - Use it on a fainted teammate. On a successful answer, it gets back up with 50% HP.
  - Only fainted teammates can be picked; the rest aren't highlighted.
- **🍃 Wake Mint** (★★★ Rare · 40 Tickets in shops):
  - Usable while at least one teammate is fainted. On a successful answer, every fainted teammate gets back up with 50% HP.
- **When nobody has fainted:** both items show greyed out in the item list, with "Nobody has fainted."
- **Answers:**
  - A Make-Up answer can fumble the item, which keeps it but has no effect, like other items.
  - A wrong answer uses it up with no effect.
- **Where to find them:** both turn up like other items, in floor drops, chests, Kecleon Shops and Battle Tower rewards.
