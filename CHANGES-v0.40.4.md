# PokémonCollege v0.40.4

## Hints never remove answers
- **What hints do now:** hints only explain. Each tap shows the next step, and the button disappears after the last step.
- **What changed:** the old "remove wrong answers" option, which came after the last step in v0.40.0, is gone, so you can't narrow the choices down and guess anymore.
- **Term and quiz questions:** these still get their one gentle hint, like the first letter and word count or a key word.
