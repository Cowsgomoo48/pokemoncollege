# PokémonCollege v0.35.0

## PokéPics
- **Bigger folders:** folders now hold up to 25,000 characters of text, up from 6,000. Folders split at the old limit are merged back automatically the first time the app opens, then split again only if they're still too big.
- **Groups (folders of folders):**
  - ＋ NEW GROUP on the PokéPics home screen.
  - Inside a folder, 📂 moves it into a group or back to the main list.
  - Groups can be renamed or removed. Removing a group keeps its folders.
  - Auto-split parts ("Math (2)" and so on) always land in the same group, named after the original.
- **One AI guide at a time:** AI study guides are built one folder after another instead of all at once.

## Summaries
- **Summary folders:**
  - ＋ NEW SUMMARY FOLDER on the Summaries page.
  - Pick a folder for any summary in its editor.
  - Folders can be renamed or removed. Removing one keeps its summaries.
- **Automatic folders:** each PokéPics group also shows up on the Summaries page as an automatic folder (📷) holding that group's summaries.
- **Minigame setup:** study sets are grouped by folder, with one checkbox to select a whole folder.
