# PokémonCollege v0.56.0

## New Pokémon
- **Gothita → Gothorita → Gothitelle** (Psychic). Rarity: Common → Uncommon → Very Rare.
- **Hatenna → Hattrem → Hatterene** (Psychic; Hatterene is Psychic/Fairy). Rarity: Common → Uncommon → Very Rare.
- **Evolution costs:** 5 Rare Candies for the first evolution and 20 for the second, like the other three-stage lines.
- **Moves:**
  - Gothitelle uses Confusion or Charm, and Psychic or Future Sight.
  - Hatterene uses Confusion or Fairy Wind, and Psychic or Dazzling Gleam.
  - The earlier stages use the usual Psychic-type moves.
  - All six can learn TMs from their main-game learnsets.
- **Sprites:** full animated sprites (walk, idle, attack, sleep) and portraits from PMD SpriteCollab. Costume hats line up on them too.
- **Where to find them:** in the Safari and as dungeon and Tower foes like any other Pokémon. The roster is now 166 species.
