# PokemonCollege v0.62.7

## Run Bag (Mystery Dungeon / Tower items)
- **ITEM** now opens a **Run Bag** sheet that slides up from the bottom, styled like the main-menu Bag, instead of the long button list that couldn't scroll to the bottom.
- Items show as round slots with their counts. **Tabs:** All, Healing, Attack, Boosts (a tab only appears when you have something in it).
- Tap a slot to see the item's name, count and what it does, with a **USE** button.
- Items you can't use right now (Smelling Salts / Wake Mint when nobody has fainted) are greyed out, the reason is shown, and USE is disabled.
- The grid scrolls inside the sheet, so every item can be reached.
- Closing the sheet (✕, the handle or tapping outside) returns to the battle without using your turn.
- Targeting after USE (pick a teammate or foe, Cancel) works the same as before.
