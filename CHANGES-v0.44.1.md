# PokémonCollege v0.44.1

## Workout Gym toned down
- **Starting chance:** 5% → 1%. A miss still doubles it (1 → 2 → 4 → 8 → 16 → 32 → 64 → 100%), so a boost takes about 7–8 hours instead of about 4.
- **Level starting chances:** 1 / 1 / 1 / 1.25 / 1.25 / 1.5 / 1.5 / 1.75 / 2 / 2.5%. The EXP and sleep-time bonuses are unchanged.
- **Training EXP:** halved. An hour trained is now worth half an hour as your companion.
- **Overall (simulated):** about 2.9 growth boosts a day instead of 4, and a little over half the EXP. Facilities also level up about half as fast, since they earn the same EXP.
