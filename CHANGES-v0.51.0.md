# PokémonCollege v0.51.0

## 🎒 Bag
- **5 per row:** items now sit 5 to a row in every tab, with slightly smaller icons.
- **No more stacking:** every slot has a fixed size, so slots no longer overlap when you have a lot of items. The list just gets longer and scrolls.
- **Closed during minigames:** the bag can't open while a minigame, dungeon or Tower run is on screen, or while a study question is up. That includes swiping up from the bottom bar. The 🎒 tab is also hidden then. It works again as soon as you leave the game.
