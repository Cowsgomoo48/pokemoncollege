# v0.70.3 — Help me start on DIY problems

- Do It Yourself problems use the same guided start as other questions.
  - When the problem's bundled solution has a clear equation and setup, you choose the equation, then the substitution, before the work lines and CHECK MY WORK unlock.
  - Otherwise, **Help me start / Help with the next step** gives the solution's steps one at a time.
- In dungeon/Tower questions, finishing both setup steps on a DIY problem earns the same +2 Tickets as other guided questions.
